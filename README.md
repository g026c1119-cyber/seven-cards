# ASCII七並べ ― 迷わず遊べる版

## ゲームの概要
ターミナルで遊ぶ七並べです。あなた1人とCPU 3人で対戦し、最初に手札が0枚になった人の勝ちです。
元のゲームを遊んだとき「何を入力すればいいか」「画面のどこを見ればいいか」が分かりにくかったため、初心者でも迷わず遊べるように改良しました。

## 動作環境
- Python 3.13（〔3.10以降で動作すると思われますが未確認〕）
- 外部ライブラリは不要です

## インストール方法
```
git clone 〔このリポジトリのURL〕
cd 〔リポジトリ名〕
```

## 起動方法
```
py w14_ascii_seven_cards.py
```
（Mac・Linuxの場合は `python3 w14_ascii_seven_cards.py`）

## 操作方法
- `S6`、`H10`、`DA` のように「マーク＋数字」を入力して札を出します（S=スペード、H=ハート、D=ダイヤ、C=クラブ、A/J/Q/K も使えます）
- `P`：パス（出せる札がないとき）
- `Q`：ゲームを終了
- 各マークの7から、となりの数字を順番につなげます

### 画面の記号
- `*`：手札の中で、今出せる札
- `+`：場の表で、次に置ける場所
- `.`：まだ置かれていない場所

## 追加・改良した機能

### 改良機能01：場に「次に置ける場所」を表示
場の表で、次に札を置ける位置に `+` を表示するようにしました。どこに置けるかが一目で分かります。
（`show_board()` を変更）

### 改良機能02：CPUの行動まとめを表示
自分の番の最初に、前回からCPU 3人が何をしたか（どの札を出したか・パスしたか）をまとめて表示するようにしました。画面が流れても、CPUの動きを見落としません。
（`cpu_turn()` が行動を文字で返すようにし、`main()` でリストにためて表示）
